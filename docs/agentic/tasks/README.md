# Task cards

Create one card per bounded implementation task from
[`../task-template.md`](../task-template.md). Name it
`wave-<n>-<short-name>.md`. A task card is committed with the implementation it
governs and must contain its test evidence before review.

Do not create cards merely for conversations. The Planner creates a card when a
task is ready to be claimed.

Wave cards `wave-0` through `wave-9` are the roadmap slices from
[`../../implementation-plan.md`](../../implementation-plan.md). Claim a later
wave only after the previous wave's definition of done is met.
