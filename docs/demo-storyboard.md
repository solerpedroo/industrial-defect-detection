# Demo storyboard

Record this after Wave 6, when inference returns real maps. Target length: 2–3 minutes.

1. **Overview** — state the three inspection questions and the two model families.
2. **Datasets** — show Bottle, Leather, and Metal Nut counts and the non-commercial license.
3. **Inference Lab** — upload one anomalous image, select a category and a model, show score, heatmap, and overlay.
4. **Comparison** — same image, autoencoder versus PatchCore.
5. **Experiments** — open protocol A and point at the saved metrics, including one failure case.
6. **Close** — say that scores are not physical severity and that thresholds came from validation.

Do not show dataset files in a way that republishes the MVTec images beyond what the license allows for the video's context. Prefer a short fair-use style demonstration and link the official dataset page.
